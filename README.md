# Hellrasher Music Studio

Aktuální verze: **0.2.96**

Stabilnější ladění časů: kliknutí a dvojklik neposouvají stopu, dvojklik přehraje přesný úsek a zvětšení zachová prohlíženou část skladby. Zelené značky nahrazuje neutrální vzhled se zlatými prvky HMS.

Použijte aktualizátor v HMS. Tento repozitář obsahuje pouze distribuční soubory; zdrojový kód je soukromý.

[Poznámky k vydání](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/tag/v0.2.96)

Projekty, média, modely a uložená nastavení se zachovávají. Nové modelové soubory nejsou potřeba.
