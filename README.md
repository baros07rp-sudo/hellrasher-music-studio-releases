# Hellrasher Music Studio

Aktuální verze: **0.2.91**

Automatická režie spojuje příběh, hudbu, text a emoce. Aktualizace opravuje návaznost, práci s kamerou a rozložení rozhraní.

Použijte aktualizátor v HMS. Tento repozitář obsahuje pouze distribuční soubory; zdrojový kód je soukromý.

[Poznámky k vydání](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/tag/v0.2.91)

K dispozici jsou podepsané instalační soubory pro Windows a metadata pro aktualizátor. Projekty, média, modely a nastavení se zachovávají. Nové generativní váhy se automaticky nestahují.
