# Hellrasher Music Studio

Aktuální verze: **0.2.95**

Větší synchronizační stopa je viditelná hned. Ruční časy se automaticky chrání před novým zarovnáním; kliknutí je neposouvá a průběžná analýza nepřepisuje ruční opravy.

Použijte aktualizátor v HMS. Tento repozitář obsahuje pouze distribuční soubory; zdrojový kód je soukromý.

[Poznámky k vydání](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/tag/v0.2.95)

Projekty, média, modely a uložená nastavení se zachovávají. Nové modelové soubory nejsou potřeba.
