# Hellrasher Music Studio

Windows studio pro tvorbu hudebních videoklipů. Aktuální verze **0.2.87**.

[Stáhnout instalačku pro Windows 64 bitů](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/download/v0.2.87/Hellrasher-Music-Studio-0.2.87-Setup.exe) · [Co je nového](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/tag/v0.2.87)

Nově podpora HMS PRO přímo ze Studia a u chyb: snímek aktuálního okna s kontrolou a začerněním, poslední technické logy a údaje o počítači. Tikety jsou na soukromém serveru našeho týmu; vlastní požadavky a odpovědi najdete v HMS. Před odesláním zkontrolujete přílohy a potvrdíte souhlas.

Stávající uživatelé mohou použít **Nastavení → Aktualizace HMS**. Novější verze nahrazuje předchozí instalaci; projekty, média, nastavení a stažené modely zachovává. SkyReels zůstává experimentální bez potvrzeného kompletního provozu na 16GB kartě.

Tento repozitář obsahuje pouze zákaznické instalační soubory, kontrolní součty a informace o vydání. Zdrojový kód je soukromý. Licenční podmínky aplikace a použitých komponent jsou součástí balíčku.
