# Hellrasher Music Studio

Aktuální verze: **0.2.97**

Director má více prostoru rozvinout concept podle příběhu, významu textu a hudby. Opravená kontrola pohybových plánů, volba rychlé nebo důkladné přípravy scén a přehlednější průběh aktualizace.

Použijte aktualizátor v HMS. Tento repozitář obsahuje pouze distribuční soubory; zdrojový kód je soukromý.

[Poznámky k vydání](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/tag/v0.2.97)

Projekty, média, modely a uložená nastavení se zachovávají. Nové modelové soubory nejsou potřeba.
