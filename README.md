# Hellrasher Music Studio

Aktuální verze: **0.2.92**

Větší náhled titulků na obrazu scény, kompaktní ovládání a sjednocené rozhraní analýzy, referencí, Studia, katalogu a exportu. Přehledné rozložení v menších i širokých oknech, světlý i tmavý vzhled.

Použijte aktualizátor v HMS. Tento repozitář obsahuje pouze distribuční soubory; zdrojový kód je soukromý.

[Poznámky k vydání](https://github.com/baros07rp-sudo/hellrasher-music-studio-releases/releases/tag/v0.2.92)

K dispozici jsou podepsané instalační soubory pro Windows a metadata pro aktualizátor. Projekty, média, modely a nastavení se zachovávají. Automatický Director zůstává zachovaný a nové generativní váhy se automaticky nestahují.
