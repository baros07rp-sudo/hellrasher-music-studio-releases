# Hellrasher Music Studio

Oficiální distribuční repozitář instalaček Hellrasher Music Studio pro Windows x64.

První zákaznické vydání se připravuje. Po jeho zveřejnění budou instalačky dostupné v sekci Releases a aktualizace přímo v aplikaci.

Free umožňuje analýzu skladby, prohlížení dřívějších projektů a omezený export s logem Hellrasher Music Studio. Pro odemyká tvorbu, úpravy a čistý export. Obrazové a video modely si uživatel nastavuje samostatně.
